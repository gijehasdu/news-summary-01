A Node 22 (standard library only) program whose summary.txt is a sourced, numbered summary of the world news of Wednesday 11 November 2026 — ten stories with figures and agency attributions, 1,969 characters. Running it validates the text (1–2,000 Unicode characters, non-whitespace) and writes it to entry.txt in the output directory.

## Run it

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out node main.ts && cat out/entry.txt
```
